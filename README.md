> **HashProof AI** is an advanced, court-aligned digital forensics console designed to ingest, authenticate, verify, and archive multimedia evidence (images, audio, and documents). Built with mathematical hashing, acoustic telemetry, dual-evidence parity comparison, and automated forensic certificate generation.

---

## 🌟 Key Forensic Modules

### 1. 🔍 Single Evidence Intelligence (Image & Document)
* Computes cryptographic bitstream digests: **SHA-256**, **SHA-1**, and **MD5**.
* Extracts and categorizes EXIF metadata (camera hardware, original acquisition timestamps, GPS coordinates).
* Detects digital post-processing footprints (e.g. Photoshop, Lightroom, GIMP, Canva).
* Verifies container integrity and color profiles.

### 2. 🎙️ Audio Forensics & Wiretap Audit
* Pure-Python acoustic stream parser supporting **WAV** and **MP3** (MPEG-1 Layer III headers).
* Extracts sampling frequency (Hz), channel topology (Mono/Stereo), bit depth / bitrate, and total PCM frame counts.
* Interactive visual waveform envelope to inspect cut points, splices, and volume dropouts.
* Verifies raw bitstream hashes directly from audio binary stream.

### 3. ⚖️ Dual-Evidence Parity Comparator (A vs B)
* Side-by-side comparative examination of a reference asset vs. suspect copy.
* Detects whether an asset was re-saved, cropped, recompressed, or altered down to the individual bit.
* Generates comparative parity matrices with clear verdicts: **Parity Verified** vs **Alteration Detected**.

### 4. 🧪 Cryptographic Avalanche Simulation Lab
* Interactive demonstration of cryptographic diffusion.
* Shows how modifying even 1 character in a document completely transforms all 64 hexadecimal characters of the SHA-256 digest.

### 5. 📄 Multi-Format Forensic Report Generation
* **Official Forensic Certificate (`.html` / PDF)**:
  * Branded, print-ready certificate with built-in **`🖨️ Print / Save as PDF`** button.
  * Embedded print stylesheet (`@media print`) formats perfectly on standard Letter / A4 paper.
  * Contains cryptographic stamps, hash verification tables, telemetry breakdown, and chain of custody attestation.
* **Plaintext Case Docket (`.txt`)**: Clean ASCII-bordered court docket for legal transcripts and case binders.
* **Machine Telemetry (`.json`)**: Raw cryptographic JSON artifact for automated ingestion and technical audits.

### 6. 🗄️ SQLite Examination Archive & Merkle Chain of Custody
* ACID-compliant local database storing every examined asset with parameterized queries.
* Fast search by filename, report ID, or cryptographic hash.
* Chain-of-custody tracking ensuring non-destructive record management.

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/lookingfor-vanilla/ai-authenticator.git
cd ai-authenticator
```

### 2. Create and Activate Virtual Environment
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Launch the Platform
```bash
streamlit run app.py
```
Open your browser to `http://localhost:8501`.

## 🏛️ Standards & Legal Admissibility

HashProof AI generates examination records aligned with digital evidence standards:
* **NIST FIPS 180-4**: Standardized cryptographic hashing algorithms directly on unaltered bitstreams.
* **Federal Rules of Evidence (FRE) Rule 902(13)**: Self-authenticating certified records generated by an electronic process or system.
* **Federal Rules of Evidence (FRE) Rule 902(14)**: Certified data copied from an electronic device, storage medium, or file authenticated by hash value.
